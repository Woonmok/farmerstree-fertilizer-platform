## 자동화 점검 결과 (완료)

| 항목 | 결과 |
|---|---|
| JS 문법 검사 (17개 파일) | ✅ 전원 이상 없음 |
| ESLint 오류 | ✅ 0건 (경고 6건 — 아래 참고) |
| 계산 로직 단위 테스트 (18개) | ✅ 18/18 통과 |

### ESLint 경고 내역 (오류 아님, 참고용)

| 파일 | 경고 내용 |
|---|---|
| `biochar-calculator/app.js` | `biocharKg` 변수 선언 후 미사용 (출력에만 사용) |
| `farmer-roi-calculator/app.js` | `onProductChange`, `onAreaUnitChange` — HTML onclick에서 호출되므로 실제 미사용 아님 |
| `farmer-roi-calculator/app.js` | `chemRevenue` 계산은 하지만 결과에 미출력 (향후 활용 예정인 경우 유지 가능) |
| `farmer-roi-calculator/app.js` | `copySummary`, `exportCSV` — HTML onclick에서 호출됨 |

> `onProductChange`, `onAreaUnitChange`, `copySummary`, `exportCSV`는 HTML `onclick` 속성에서 직접 호출하므로 실제 버그 아님. ESLint가 HTML을 인식 못 해 발생하는 false positive.

## 브라우저 수동 점검 방법

로컬에서 정적 서버 실행 후 각 페이지 접속:

```bash
# 프로젝트 폴더에서 실행
cd farmerstree-fertilizer-platform
npx serve .
# 또는
python3 -m http.server 8080
```

## 모듈별 체크리스트

### 1. 홈 (`index.html`)
- [ ] 페이지 정상 로딩
- [ ] 각 모듈 링크 클릭 시 해당 페이지 이동
- [ ] 콘솔 오류 없음

---

### 2. 배치 기록 생성기 (`batch-generator/`)
- [ ] 페이지 로딩 시 제조일자 자동 오늘 날짜 입력
- [ ] 레시피 유형 3가지(A/B/C) 전환 시 배합표 갱신 확인
- [ ] 후배지 투입량 변경 시 배합량 자동 재계산 확인
- [ ] 미리보기에 Markdown 정상 생성
- [ ] **[복사] 버튼** → 클립보드 복사 알림 표시
- [ ] **[다운로드] 버튼** → `.md` 파일 다운로드
- [ ] 제조번호 빈 칸 → 파일명 `farmerstree-batch-record.md`로 저장

---

### 3. 비용 계산기 (`calculator/`)
- [ ] 모든 입력값 변경 시 실시간 자동 계산
- [ ] bags=0 입력 → 비용·수익 0원 표시
- [ ] 판매가=0 → 마진율 0% 표시 (크래시 없음)
- [ ] 보조금 > 판매가 → 농가 체감가 0원 표시 (음수 없음)
- [ ] 마진율에 따른 사업성 메시지 3단계 정상 전환

---

### 4. 레시피 계산기 (`recipe-calculator/`)
- [ ] 후배지 투입량 변경 시 전체 배합량 실시간 갱신
- [ ] A/B/C안 전환 정상 동작
- [ ] 특허 잠금 배합비 테이블 자동 갱신
- [ ] 투입량 0 입력 → 0kg 표시 (크래시 없음)

---

### 5. 바이오차 계산기 (`biochar-calculator/`)
- [ ] 정상 입력값으로 전체 계산 확인
- [ ] **목표수분 100% 이상 입력** → "목표 수분은 100% 미만이어야 합니다." 에러 표시, 계산 중단
- [ ] 혼합비 0% → "biochar를 제품에 넣지 않는 조건" 메시지 표시
- [ ] 포대당 순이익 음수 시 경고 메시지 표시

---

### 6. 리포트 생성기 (`report-generator/`)
- [ ] 제조번호 미입력 → "제조번호를 입력하세요." 안내 표시
- [ ] 두 CSV 중 하나만 첨부 → 에러 메시지 표시
- [ ] **정상 CSV 2개 첨부** + 제조번호 입력 → 리포트 생성
- [ ] 빈 CSV(0바이트) 첨부 → "제조번호 컬럼을 찾을 수 없습니다." 메시지 (크래시 없음)
- [ ] 일치하는 제조번호 없음 → 리포트에 "해당 데이터 없음" + 건수 0건 표시
- [ ] 다운로드 버튼 → `.md` 파일 저장

> **테스트용 CSV 샘플**
>
> 발효 온도 CSV:
> ```
> 제조번호,일차,오전온도,오후온도
> FT-TEST-001,1,55,60
> FT-TEST-001,2,58,62
> ```
>
> 품질검사 CSV:
> ```
> 검사일,제조번호,수분,pH,최종판정
> 2026-06-01,FT-TEST-001,17,7.0,합격
> ```

---

### 7. 농가 ROI 시뮬레이터 (`farmer-roi-calculator/`)
- [ ] 작물 선택 변경 시 기본값 자동 로드
- [ ] 제품 A/B/C 전환 시 설정값 갱신
- [ ] 커스텀 면적 선택 → 면적 입력창 표시, 라벨에 입력한 면적 단위 반영
- [ ] 보조율 100% → FT비료 순비용 0원
- [ ] 순이익 음수 시 빨간색 표시
- [ ] **[문구 복사] 버튼** → 복사 성공/실패 피드백
- [ ] **[CSV 내보내기] 버튼** → BOM 포함 CSV 다운로드

---

### 8. 탄소 리포트 (`carbon-report/`)
- [ ] 입력 후 [생성] 클릭 → ESG 문구 / 공공사업 문구 자동 생성
- [ ] [ESG 복사], [공공 복사] 버튼 동작
- [ ] 수치 0 입력 → 0 표시, 크래시 없음

---

### 9. 토양·탄소 계산기 (`soil-carbon-calculator/`)
- [ ] 바이오차 혼합비 0% → "일반 후배지 펠릿비료" 안내 메시지
- [ ] CO₂e 계산값 = 안정화 탄소량 × 3.667 (44/12) 검증
- [ ] 리포트 복사 / 다운로드 정상 동작
